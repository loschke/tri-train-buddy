# Periodization (Periodisierung)

## Definition

Periodization is the systematic planning of athletic training by dividing the training year into specific phases, each with distinct goals, training methods, and intensities. The goal is to peak performance at the right time while minimizing injury risk and overtraining.

## Core Principles

### 1. Progressive Overload
- Gradual increase in training stress (volume, intensity, frequency)
- Typical increase: 5-10% per week
- NEVER increase volume AND intensity simultaneously

### 2. Specificity
- Training adaptations are specific to the training stimulus
- As race approaches, training becomes more race-specific

### 3. Reversibility
- "Use it or lose it" - fitness decays without training
- Aerobic fitness decays slower than anaerobic
- Detraining begins after 10-14 days of inactivity

### 4. Individual Response
- Same training yields different results for different athletes
- Monitor individual response and adjust accordingly

## Classic Periodization Model (Linear)

### Phase 1: Base/Preparation Phase
**Duration**: 8-16+ weeks before race
**Volume**: High (70-80% of peak)
**Intensity**: Low (80% in Zone 1-2)

**Goals**:
- Build aerobic foundation
- Increase training tolerance
- Develop technique
- Build structural strength (tendons, ligaments)

**Training Focus**:
- Long, slow distance (LSD)
- High volume, low intensity
- Frequency over intensity
- General strength training

**Key Metrics**:
- Increase weekly volume by 10% max
- Majority of sessions at conversational pace
- Focus on consistency

**Example Week (Triathlon)**:
```
Monday:    Rest
Tuesday:   Run 60min Z1-2 + Strength
Wednesday: Bike 90min Z1-2
Thursday:  Swim 45min technique + Strength
Friday:    Run 45min Z2
Saturday:  Bike 3h Z1-2 (long ride)
Sunday:    Run 90min Z1-2 (long run)

Total: ~12-15 hours
```

---

### Phase 2: Build Phase
**Duration**: 8-16 weeks before race
**Volume**: Very High (85-100% of peak)
**Intensity**: Moderate (70% Z1-2, 20% Z3, 10% Threshold)

**Goals**:
- Progressive load increase
- Introduce tempo/threshold work
- Build race-specific endurance
- Increase lactate threshold

**Training Focus**:
- Continued volume increase
- Add tempo sessions (20-40min at threshold)
- Hill work (running/cycling)
- Longer intervals (5-10min reps)
- Sport-specific strength

**Progressive Overload Strategy**:
```
Week 1: 100% baseline
Week 2: 110% (increase volume)
Week 3: 120% (increase volume)
Week 4: 70% (recovery week - CRITICAL!)
Week 5: 125% (resume building)
...
```

**Example Week (Triathlon)**:
```
Monday:    Rest
Tuesday:   Run 60min with 3x10min Z3
Wednesday: Bike 90min Z2
Thursday:  Swim 60min with intervals + Strength
Friday:    Run 45min easy Z1
Saturday:  Brick: Bike 2h Z2-3 → Run 30min Z2
Sunday:    Run 2h Z1-2 (long run)

Total: ~15-18 hours
```

---

### Phase 3: Peak/Sharpening Phase
**Duration**: 4-8 weeks before race
**Volume**: High (80-90% of peak)
**Intensity**: High (60% Z1-2, 25% Z3, 15% Threshold/VO2max)

**Goals**:
- Race-specific intensity
- Sharpen speed and power
- Practice race nutrition
- Mental preparation

**Training Focus**:
- Race-pace sessions
- Shorter, higher-intensity intervals (1-5min)
- Brick workouts (bike→run transitions)
- Practice race-day logistics
- Reduce volume slightly, maintain intensity

**Intensity Distribution**:
- 2-3 high-intensity sessions per week
- All other sessions recovery/easy
- NO "moderate" intensity (avoid "junk miles")

**Example Week (Triathlon)**:
```
Monday:    Rest
Tuesday:   Run 60min with 20min race pace
Wednesday: Bike 90min with 3x15min Z4 (FTP)
Thursday:  Swim 60min race pace sets + Light strength
Friday:    Run 40min easy Z1
Saturday:  Brick: Bike 2h (60min Z2, 60min Z3) → Run 60min Z2-3
Sunday:    Run 90min with 30min race pace

Total: ~13-16 hours
```

---

### Phase 4: Taper Phase
**Duration**: 2-4 weeks before race
**Volume**: Reduced (50-70% of peak)
**Intensity**: Low with occasional sharpeners
**Frequency**: Maintain (don't drop number of sessions drastically)

**Goals**:
- Full physical recovery
- Mental freshness
- Glycogen supercompensation
- Peak on race day

**Taper Rules**:
1. **Reduce volume by 30-50%**
2. **Maintain intensity** (with shorter durations)
3. **Keep frequency** (maintain training rhythm)
4. **Reduce strength training** (maintenance only)
5. **Prioritize sleep and nutrition**

**Taper Duration by Race Distance**:
```
Sprint Triathlon:     7-10 days
Olympic Triathlon:    10-14 days
Half Ironman:         14-21 days
Ironman:              21-28 days
Marathon:             14-21 days
```

**Example Week -2 (Ironman Taper)**:
```
Monday:    Rest
Tuesday:   Run 40min Z2 with 3x5min race pace
Wednesday: Bike 60min Z2 with 3x10min Z3
Thursday:  Swim 30min easy + VERY light strength
Friday:    Rest or easy 20min run
Saturday:  Brick: Bike 90min easy → Run 20min Z2
Sunday:    Run 60min easy Z1-2

Total: ~6-8 hours (down from 15-20h peak)
```

**Example Race Week (Final 7 Days)**:
```
Monday:    Swim 20min easy + Run 20min Z1
Tuesday:   Bike 30min Z2 with 3x3min race pace
Wednesday: Swim 20min easy
Thursday:  Rest or 15min run Z1
Friday:    Rest
Saturday:  RACE DAY!
Sunday:    Active recovery (light swim/walk)
```

## Alternative Models

### Block Periodization (Modern Approach)

**Concept**: Focus on 1-2 abilities per 2-4 week block

**Blocks**:
1. **Accumulation Block** (4 weeks)
   - High volume, low intensity
   - Build aerobic base

2. **Intensification Block** (3 weeks)
   - Reduce volume 20-30%
   - Increase intensity (threshold work)

3. **Realization Block** (2 weeks)
   - Race-specific work
   - High intensity, lower volume

4. **Recovery Block** (1 week)
   - Active recovery
   - Prepare for next cycle

**Advantages**:
- More focused training stimulus
- Faster adaptations
- Better for experienced athletes

**Disadvantages**:
- Risk of losing fitness in non-focused areas
- Requires disciplined execution

---

### Reverse Periodization (Endurance Sports)

**Concept**: Start with intensity, then build volume

**Use Cases**:
- Hot weather races (need heat adaptation)
- Weak aerobic base (already strong at threshold)
- Time-crunched athletes

**Phases**:
1. **Intensity First** (8 weeks)
   - Low volume, high intensity
   - Build FTP/threshold

2. **Volume Addition** (8 weeks)
   - Maintain intensity sessions
   - Add endurance volume

3. **Race-Specific** (4 weeks)
   - Combine both

## Periodization for Different Goal Races

### Single Peak (One Main Race)

```
24 weeks out: Base Phase begins
16 weeks out: Build Phase begins
8 weeks out:  Peak Phase begins
3 weeks out:  Taper begins
Race Day:     PEAK PERFORMANCE
Post-race:    2-4 weeks recovery
```

### Double Peak (Two Main Races)

**Spring Race (e.g., May) + Fall Race (e.g., September)**

```
January-March:    Base Phase (12 weeks)
April:            Build Phase (4 weeks)
May:              Peak + Taper (3 weeks)
RACE 1 (May)
June:             Recovery + Base (4 weeks)
July-August:      Build Phase (8 weeks)
September:        Peak + Taper (3 weeks)
RACE 2 (September)
October-December: Off-season recovery
```

### Multiple Races (Season-Long)

**Strategy**: Maintain base fitness, mini-tapers for key races

```
Every 8-12 weeks: Include 1 recovery week
Key Races:        3-7 day mini-taper
B/C Races:        Train through (no taper)
A Race:           Full 2-3 week taper
```

## Recovery Weeks (Critical!)

### Why Recovery Weeks Matter

**Supercompensation**: Fitness gains occur during recovery, not training

**Frequency**: Every 3-4 weeks of building

**Volume Reduction**: 40-50% of previous 3-week average

**Intensity**: Keep some sharpeners, but mostly easy

**Example 4-Week Microcycle**:
```
Week 1: 100% (baseline)
Week 2: 110% (build)
Week 3: 120% (peak load)
Week 4: 60%  (RECOVERY) ← Critical!
Week 5: 125% (resume building from higher baseline)
```

**Signs You Need a Recovery Week**:
- Elevated resting heart rate (>5 bpm higher than normal)
- Poor sleep quality
- Persistent muscle soreness
- Declining performance in workouts
- Mental fatigue / lack of motivation
- Increased susceptibility to colds

## Age-Related Periodization Adjustments

### Masters Athletes (40+ years)

**Key Differences**:
- Slower recovery (need more recovery time)
- Higher injury risk
- Better fat oxidation (advantage in ultra-endurance)

**Adjustments**:
- More frequent recovery weeks (every 2-3 weeks instead of 3-4)
- Lower volume peaks (10-15% less than younger athletes)
- More emphasis on strength/mobility
- Avoid back-to-back hard days
- Longer taper (add 25-50% more taper time)

**Example**:
```
Age 25: 3 weeks build → 1 recovery
Age 45: 2 weeks build → 1 recovery
```

## Common Periodization Mistakes

### ❌ Mistake 1: No Recovery Weeks
**Problem**: Accumulating fatigue, eventual breakdown
**Solution**: Scheduled recovery every 3-4 weeks

### ❌ Mistake 2: Too Much Intensity Too Soon
**Problem**: Skipping base phase, going straight to intervals
**Solution**: Minimum 8-12 weeks base before adding intensity

### ❌ Mistake 3: Constant Moderate Intensity
**Problem**: "Grey zone" training (not easy, not hard)
**Solution**: Polarized training (80% easy, 20% hard)

### ❌ Mistake 4: Increasing Volume AND Intensity
**Problem**: Exponential stress increase, injury risk
**Solution**: Increase ONE variable at a time

### ❌ Mistake 5: Insufficient Taper
**Problem**: Arriving at race fatigued
**Solution**: Full 2-4 week taper for long-distance events

### ❌ Mistake 6: Training Through Illness
**Problem**: Prolonged recovery, weakened immune system
**Solution**: "Neck check" - if symptoms below neck, rest completely

## Tracking Periodization Success

### Key Metrics to Monitor

**Weekly**:
- Training Stress Score (TSS) / Training Load
- Resting Heart Rate (morning)
- Sleep Quality (hours + subjective)
- Motivation Level (1-10 scale)

**Monthly**:
- Functional Threshold Power (FTP) test
- Lactate Threshold Pace test
- Body composition
- Strength benchmarks

**Quarterly**:
- VO2max test (optional)
- Race simulations
- Review annual plan progress

### Tools for Periodization

**Software**:
- TrainingPeaks (TSS, CTL, ATL, TSB)
- Today's Plan
- Garmin Connect (Training Load)
- Strava Fitness & Freshness

**Manual Tracking**:
- Weekly volume (hours or km)
- Intensity distribution (% in each zone)
- Subjective wellness scores
- Performance benchmarks

## Key Takeaways for AI Training Plan Generation

✅ **Always include recovery weeks** (every 3-4 weeks)
✅ **Respect training phases** (base → build → peak → taper)
✅ **Progressive overload** (max 10% increase per week)
✅ **80/20 intensity distribution** (base/build phases)
✅ **Taper duration scales with race distance** (2-4 weeks for Ironman)
✅ **Never increase volume AND intensity simultaneously**
✅ **Phase-appropriate training** (no intervals in base phase!)
✅ **Individual response** (allow user feedback to modify plans)
