# Strength Training for Endurance Athletes

## Purpose of Strength Training

### Benefits for Endurance

✅ **Injury Prevention** (primary goal)
✅ **Improved economy** (less energy for same pace)
✅ **Power development** (sprints, hills, accelerations)
✅ **Muscular endurance**
✅ **Bone density** (especially important for runners)
✅ **Muscle imbalance correction**

### Misconceptions

❌ "Strength training makes you bulky" → No (wrong training type)
❌ "Cardio is enough" → No (different adaptations)
❌ "I don't have time" → 30-45min 2x/week sufficient

## Periodization of Strength Training

### Base Phase (Off-Season / Early Preparation)

**Goal**: Build foundation, anatomical adaptation

**Volume**: 2-3× per week
**Sets/Reps**: 3×12-15 (lighter weight)
**Exercises**: Full body, compound movements
**Focus**: Form, stability, mobility

**Example Session**:
```
1. Goblet Squat: 3×15
2. Push-ups: 3×12-15
3. Romanian Deadlift: 3×12
4. Plank: 3×45sec
5. Side Plank: 3×30sec each
6. Glute Bridge: 3×15
```

### Build Phase (Preparation)

**Goal**: Maximal strength development

**Volume**: 2× per week
**Sets/Reps**: 4×6-8 (heavier weight)
**Exercises**: Compound, sport-specific
**Focus**: Progressive overload

**Example Session**:
```
1. Back Squat: 4×6-8 @ 75-85% 1RM
2. Deadlift: 3×6
3. Bench Press / Push-ups: 3×8
4. Pull-ups / Rows: 3×8
5. Single-Leg RDL: 3×8 each
6. Core circuit: 10min
```

### Peak / Race Phase (In-Season)

**Goal**: Maintain strength, minimize fatigue

**Volume**: 1-2× per week
**Sets/Reps**: 2-3×8-10 (moderate)
**Exercises**: Functional, maintenance
**Focus**: Efficiency, minimal DOMS

**Example Session**:
```
1. Bulgarian Split Squat: 3×10 each
2. Push-ups: 2×12
3. Single-leg Deadlift: 2×10 each
4. Plank variations: 3×30-45sec
5. Clamshells: 2×15 each
```

### Taper (2-4 Weeks Before A-Race)

**Goal**: Maintain without fatigue

**Volume**: 1× per week (or stop 10-14 days out)
**Sets/Reps**: 2×6-8 (maintenance)
**Focus**: Very light, no soreness

**Example**:
```
Light bodyweight circuit:
- Squats: 2×10
- Push-ups: 2×10
- Lunges: 2×10 each
- Plank: 2×30sec
```

## Key Exercises for Endurance Athletes

### Lower Body (Running/Cycling Focus)

**1. Squats** (Quad, glute, core strength)
```
Variations:
- Goblet squat (beginner)
- Back squat (advanced)
- Front squat (core emphasis)

Sets/Reps: 3-4×6-12
Frequency: 1-2×/week
```

**2. Deadlift** (Posterior chain, hamstrings, glutes)
```
Variations:
- Romanian deadlift (hamstring focus)
- Single-leg deadlift (balance, running-specific)
- Conventional deadlift (full body)

Sets/Reps: 3×6-10
Frequency: 1-2×/week
```

**3. Lunges / Split Squats** (Single-leg strength, balance)
```
Variations:
- Walking lunges
- Reverse lunges
- Bulgarian split squats (elevated rear foot)

Sets/Reps: 3×8-12 each leg
Frequency: 2×/week
```

**4. Calf Raises** (Achilles strength, running economy)
```
Variations:
- Straight leg (gastrocnemius)
- Bent knee (soleus)

Sets/Reps: 3×15-20
Frequency: 2-3×/week (high volume OK)
```

**5. Hip Thrusts / Glute Bridges** (Glute activation)
```
Single-leg progression for running

Sets/Reps: 3×12-15
Frequency: 2-3×/week
```

**6. Step-Ups** (Running-specific, power)
```
Use box height = knee level

Sets/Reps: 3×10 each leg
Frequency: 1-2×/week
```

### Core / Stability

**7. Planks** (Core endurance)
```
Variations:
- Front plank: Hold 30-60sec
- Side plank: 30-45sec each
- Plank with leg lift

Sets: 3×30-60sec
Frequency: Daily OK
```

**8. Dead Bug** (Core stability, anti-rotation)
```
Slow, controlled movement

Sets/Reps: 3×10 each side
Frequency: 3-4×/week
```

**9. Bird Dog** (Balance, coordination)
```
Opposite arm/leg extension

Sets/Reps: 3×10 each side
Frequency: 3-4×/week
```

**10. Russian Twists** (Obliques, rotation)
```
Use medicine ball or weight

Sets/Reps: 3×20 (10 each side)
Frequency: 2-3×/week
```

### Upper Body (Swimming/Cycling Focus)

**11. Push-Ups** (Chest, triceps, core)
```
Variations:
- Standard
- Diamond (triceps)
- Wide (chest)

Sets/Reps: 3×10-20
Frequency: 2-3×/week
```

**12. Pull-Ups / Rows** (Back, biceps, posture)
```
Pull-ups OR
Inverted rows OR
Band rows

Sets/Reps: 3×6-12
Frequency: 2-3×/week
```

**13. Shoulder Press** (Shoulder stability)
```
Dumbbell or barbell

Sets/Reps: 3×8-12
Frequency: 1-2×/week
```

### Injury Prevention (Must-Do)

**14. Clamshells** (Hip abductors, glutes)
```
Side-lying, band resistance

Sets/Reps: 3×15-20 each
Frequency: Daily (easy, low fatigue)
```

**15. Monster Walks** (Hip stability)
```
Band around thighs, walk sideways

Sets: 3×20 steps each direction
Frequency: 3-4×/week
```

**16. Single-Leg Balance** (Ankle stability, proprioception)
```
Stand on one leg: 30-60sec

Progress: Eyes closed, unstable surface

Frequency: Daily
```

## Sample Weekly Schedules

### Runner (40-60 km/week)

```
Monday:    Rest
Tuesday:   Run (intervals) AM + Strength (lower body) PM
Wednesday: Easy run
Thursday:  Run (tempo)
Friday:    Strength (core/stability) + Easy run
Saturday:  Long run
Sunday:    Easy run or rest
```

**Strength Sessions**:
- **Tuesday**: Squats, deadlifts, lunges, calf raises (45min)
- **Friday**: Core circuit, clamshells, monster walks (30min)

### Cyclist (8-12 hours/week)

```
Monday:    Rest or light strength
Tuesday:   Bike (intervals) + Strength (full body)
Wednesday: Bike (endurance)
Thursday:  Bike (sweet spot)
Friday:    Strength (core/upper) + Easy spin
Saturday:  Long bike
Sunday:    Bike (recovery) or rest
```

**Strength Sessions**:
- **Tuesday**: Squats, deadlifts, push-ups, rows (45min)
- **Friday**: Core, shoulder stability, mobility (30min)

### Triathlete (10-15 hours/week)

```
Monday:    Swim + Core
Tuesday:   Bike (intervals) + Run (easy)
Wednesday: Swim + Strength (full body)
Thursday:  Bike (endurance)
Friday:    Run (tempo) + Strength (core)
Saturday:  Long bike + Short brick run
Sunday:    Long run
```

**Strength Sessions**:
- **Wednesday**: Full body (squats, deadlifts, push-ups, rows) - 45min
- **Friday**: Core, hip stability, injury prevention - 30min

## Strength Training Principles

### Progressive Overload

**Progression** (in order):
1. **Form**: Perfect technique first
2. **Reps**: Increase reps (e.g., 8 → 10 → 12)
3. **Sets**: Add sets (e.g., 2 → 3 → 4)
4. **Weight**: Increase load by 5-10%
5. **Tempo**: Slow eccentric (3-4sec down)

**Weekly Increase**: 2-5% load OR 1-2 reps

### Recovery

**Between Sets**: 1-3min (strength focus)
**Between Sessions**: 48 hours (same muscle group)
**Muscle Soreness**: OK for 24-48h, not desirable in-season

### Form Over Weight

**Priority**: Perfect form > heavy weight
- Squats: Knees track over toes, chest up, depth (thighs parallel)
- Deadlifts: Neutral spine, hinge at hips
- Single-leg: No knee valgus (knee caving in)

**Common Mistakes**:
- Ego lifting (too heavy)
- Rushing reps (no control)
- Poor range of motion

## Timing with Endurance Training

### When to Strength Train

**Optimal Timing**:
1. **After easy endurance session** (low fatigue)
2. **Same day as hard session** (keeps other days for recovery)
3. **Never before key workout** (pre-fatigue risk)

**Examples**:
```
Option 1: Morning hard run → Evening strength
Option 2: Easy bike 60min → Strength immediately after
Option 3: Rest day → Strength only
```

### What to Avoid

❌ Strength day before long run (DOMS risk)
❌ Heavy squats day before bike intervals (leg fatigue)
❌ Strength same day as race (obvious)

## Injury Red Flags

### Stop Immediately If:

- Sharp pain during exercise
- Joint pain (not muscle burn)
- Loss of range of motion
- Numbness/tingling
- Swelling

### Prevention

- Warm up (5-10min light cardio + dynamic stretching)
- Progressive overload (not too fast)
- Deload weeks (every 4-6 weeks, reduce volume 40%)
- Listen to body (skip if very sore from training)

## Strength for Masters Athletes (40+)

### Key Differences

- **Higher injury risk** (longer warm-up needed)
- **Slower recovery** (48-72h between sessions)
- **Sarcopenia** (muscle loss with age → strength MORE important)
- **Bone density** (strength training critical)

### Adjustments

- More warm-up (10-15min)
- Lower intensity (70-80% 1RM vs 80-90%)
- Higher reps (8-12 vs 6-8)
- More recovery (2-3 days between heavy sessions)
- Emphasize injury prevention exercises

## Key Takeaways for AI Plans

✅ **2x/week minimum** (base/build phases)
✅ **1x/week in-season** (maintenance)
✅ **Full body preferred** (efficiency for time-crunched)
✅ **Compound movements** (squat, deadlift, lunges)
✅ **Core every session** (planks, stability work)
✅ **Injury prevention** (clamshells, hip work, single-leg)
✅ **Same day as hard training** (or easy training day)
✅ **Never before key workouts** (fatigue risk)
✅ **Reduce in taper** (1x/week or stop 10-14 days out)
✅ **Progressive overload** (track and increase systematically)
