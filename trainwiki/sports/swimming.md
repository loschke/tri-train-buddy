# Swimming Training

## Swim Zones (CSS-Based)

### CSS (Critical Swim Speed)

**Definition**: Fastest pace you can hold for ~30min continuous

**Testing**: T-pace test
```
400m all-out + 200m all-out (5min rest between)
CSS = Total distance (600m) / Total time

Example:
400m: 6:00 (1:30/100m)
200m: 3:10 (1:35/100m)
Total: 600m in 9:10 (550 seconds)

CSS = 1:31/100m
```

### Pace Zones

```
Zone 1 (Recovery):    CSS + 20-30 sec/100m  (1:51-2:01)
Zone 2 (Endurance):   CSS + 10-15 sec/100m  (1:41-1:46)
Zone 3 (Tempo):       CSS + 3-8 sec/100m    (1:34-1:39)
Zone 4 (Threshold):   CSS ± 2 sec/100m      (1:29-1:33)
Zone 5 (VO2max):      CSS - 5-10 sec/100m   (1:21-1:26)
```

## Key Swimming Workouts

### Endurance (Zone 2)

**Purpose**: Aerobic base, technique, efficiency
**Distance**: 2000-4000m
**Pace**: CSS + 10-15 sec

**Example**:
```
Warmup: 400m easy
Main: 10×200m @ CSS+12 (20sec rest)
Cool: 200m easy
Total: 2600m
```

### Threshold Sets (Zone 4)

**Purpose**: Increase CSS, race pace endurance
**Distance**: 100-400m reps

**Classic Sets**:
```
1. 10×100m @ CSS (10sec rest)
2. 5×200m @ CSS+2 (15sec rest)
3. 8×100m @ CSS-2 (20sec rest)
4. 20×50m @ CSS-3 (10sec rest)
```

### VO2max Intervals (Zone 5)

**Purpose**: Increase aerobic capacity
**Distance**: 25-100m reps, very fast

**Classic Sets**:
```
1. 20×50m fast (15sec rest)
2. 10×100m @ CSS-8 (20sec rest)
3. 8×75m fast (30sec rest)
```

### Technique Work

**Purpose**: Efficiency, stroke mechanics
**Frequency**: Every session (warm-up/cool-down)

**Drills** (15-20min):
```
Catch-up drill (timing, extension)
Single-arm drill (balance, rotation)
Fist drill (feel for water)
Kick sets (6×50m with board)
Pull sets (buoy, paddles) - use sparingly
```

## Swim Volume & Frequency

### Weekly Distance

**Beginner**: 3-6 km/week (2-3 sessions)
**Intermediate**: 8-12 km/week (3-4 sessions)
**Advanced**: 12-18 km/week (4-5 sessions)
**Elite Triathlete**: 15-25 km/week (5-6 sessions)

### Session Distribution

**3 sessions/week**:
```
- 1 technique + endurance
- 1 threshold set
- 1 mixed (intervals + technique)
```

**4-5 sessions/week**:
```
- 2 endurance/technique
- 1 threshold
- 1 VO2max intervals
- 1 recovery/technique focus
```

## Technique Fundamentals

### Body Position

- **Horizontal**: Hips at surface, head neutral
- **Streamlined**: Tight core, minimal drag
- **Rotation**: 30-45° body roll with each stroke

### Freestyle Stroke

**Catch**:
- High elbow
- Fingertips point down
- "Anchor" hand, pull body past it

**Pull**:
- S-curve underwater path
- Accelerate through stroke
- Finish at hip

**Recovery**:
- Relaxed arm
- High elbow
- Hand enters thumb-first, ahead of head

**Kick**:
- From hips, not knees
- Toes pointed
- 2-beat (distance) or 6-beat (sprint)

### Breathing

- Bilateral (every 3 strokes) - balanced stroke
- OR every 2 strokes (if bilateral difficult)
- Exhale underwater, quick inhale
- Minimal head rotation (one goggle out of water)

## Open Water Swimming

### Differences from Pool

- No wall push-offs (continuous swimming)
- No lane lines (navigation, sighting)
- No black line (pacing by feel/watch)
- Waves, currents, temperature
- Wetsuit (different body position)

### Open Water Skills

**Sighting**:
- Every 6-10 strokes
- Lift eyes only (not whole head)
- Sight on landmark, not buoys

**Drafting**:
- Swim behind/beside other swimmers
- 10-20% energy savings
- Practice in pool (swim close to others)

**Starts**:
- Mass start chaos
- Practice: Pool with multiple swimmers starting together

### Open Water Training

**Pool Simulation**:
```
- No push-offs (touch wall, keep swimming)
- Sighting drill (lift head every 10 strokes)
- Wetsuit swimming (if allowed)
- Tight turns (simulate buoy turns)
```

**Actual Open Water**:
- 1-2x month (if available)
- Practice race starts
- Navigation
- Acclimate to temperature

## Equipment

### Essential

- **Goggles**: Comfortable, anti-fog
- **Swim cap**: Reduces drag, protects hair
- **Swimsuit**: Snug fit

### Training Tools (Use Sparingly)

**Pull Buoy**: Isolates upper body
- Benefit: Focus on stroke
- Caution: Creates unrealistic body position

**Paddles**: Increases resistance
- Benefit: Strength, feel for water
- Caution: Shoulder injury risk (limit to 10-15% of volume)

**Fins**: Leg strength, body position
- Benefit: Kicks, drills, ankle flexibility
- Caution: Don't rely on them

**Snorkel**: Isolates stroke without breathing
- Benefit: Technique focus
- Use: Drills, not main sets

### Wetsuit (Triathlon)

**Legal**: Water <24.5°C (76°F)
**Benefits**:
- Buoyancy (faster, less energy)
- Warmth
- ~5-10% speed increase

**Practice**:
- Swim in wetsuit 3-5 times before race
- Practice quick removal (transition)

## Swimming Efficiency

### Stroke Count

**Goal**: Minimize strokes per length (SPL)

**Measurement**:
```
Count strokes for 25m
Target: 15-18 SPL (varies by height)
```

**Improvement**:
- Focus on distance per stroke (DPS)
- Glide slightly longer
- Strong catch and pull

### SWOLF Score

**Formula**: Strokes + Seconds (for 25m or 50m)
```
Example:
17 strokes + 22 seconds = SWOLF 39

Lower = better
```

**Tracking**: Weekly test, monitor progress

### Energy Conservation

**Technique over strength**:
- Poor technique = 50% more energy for same speed
- Good technique = sustainable pace

## Race-Specific Training

### Sprint Triathlon (750m)

**Focus**: Speed, sustained effort

**Key Sessions**:
```
- 10×100m @ race pace (10sec rest)
- 5×200m @ CSS (15sec rest)
- Open water simulation
```

### Olympic Triathlon (1500m)

**Focus**: Pacing, efficiency

**Key Sessions**:
```
- 3×500m @ race pace (30sec rest)
- 30×50m @ CSS-5 (15sec rest)
- Continuous 1500m time trial
```

### Half/Full Ironman (1.9-3.8km)

**Focus**: Endurance, energy conservation

**Key Sessions**:
```
- Continuous 2000-4000m @ CSS+10
- Negative split sets (2nd half faster)
- Open water 60-90min continuous
```

## Injury Prevention

### Common Issues

**Swimmer's Shoulder**:
- Cause: Overuse, poor technique, excessive paddles
- Prevention: Strengthen rotator cuff, limit paddles, proper technique

**Neck Strain**:
- Cause: Over-rotation, looking forward
- Prevention: Neutral head, bilateral breathing

### Prehab Exercises (2-3x/week)

```
Rotator Cuff:
- External rotations (band)
- Internal rotations (band)
- Y-T-W raises

Shoulder Stability:
- Scapular push-ups
- Prone Is, Ts, Ys
- Face pulls
```
