# Running Training

## Training Zones (Pace-Based)

### Zone Calculation from Threshold

**Threshold Pace**: Pace you can hold for ~60min (similar to 10K race pace +10-15 sec/km)

```
Example: Threshold Pace = 5:00/km

Zone 1 (Recovery):      6:30-7:00/km  (130-140% threshold)
Zone 2 (Easy/Aerobic):  5:50-6:30/km  (115-130% threshold)
Zone 3 (Tempo):         5:15-5:50/km  (105-115% threshold)
Zone 4 (Threshold):     4:50-5:10/km  (95-105% threshold)
Zone 5 (VO2max):        4:20-4:50/km  (85-95% threshold)
```

### Zone Calculation from Heart Rate

```
Zone 1: <70% max HR
Zone 2: 70-80% max HR
Zone 3: 80-87% max HR
Zone 4: 87-93% max HR
Zone 5: 93-100% max HR
```

### Zone Purpose

**Zone 1**: Active recovery, super easy
**Zone 2**: Aerobic base, long runs (most time here)
**Zone 3**: Tempo, minimize time here
**Zone 4**: Lactate threshold, race pace for HM/M
**Zone 5**: VO2max, 5K-10K race pace

## Key Running Workouts

### Easy/Long Runs (Zone 1-2)

**Purpose**: Build aerobic base, increase mitochondria, fat oxidation
**Frequency**: 80% of weekly volume
**Pace**: Conversational (can speak full sentences)
**Duration**: 30min - 3+ hours

**Example**:
```
Long Run: 2h at 6:00-6:15/km (Z2)
- Start slower (first 15min warm-up pace)
- Settle into rhythm
- Can include 10-20min Z3 in final third (progression)
```

**Rules**:
- NEVER run long runs hard
- Fuel if >90min (30-60g carbs/hour)
- Hydrate (water + electrolytes)

### Threshold/Tempo Runs (Zone 4)

**Purpose**: Increase lactate threshold, race-specific endurance
**Frequency**: 1x per week (build/peak phases)
**Pace**: "Comfortably hard" - can speak a few words
**Duration**: 20-60min total at threshold

**Classic Workouts**:
```
1. Continuous Tempo
   15min warmup + 30min Z4 + 10min cool

2. Cruise Intervals
   15min warmup + 3×10min Z4 (2min jog) + 10min cool

3. Progression Run
   10min Z1 → 20min Z2 → 20min Z3 → 10min Z4
```

**When**: Build and peak phases, once per week

### VO2max Intervals (Zone 5)

**Purpose**: Increase max aerobic capacity
**Frequency**: 1x per week (peak phase only)
**Pace**: 5K race pace or slightly faster
**Interval Duration**: 3-8min

**Classic Workouts**:
```
1. 6×800m at 5K pace (2:30 jog recovery)
   
2. 5×1000m at 5K pace (3min jog)

3. 4×1600m at 10K pace (3min jog)

4. Hill Repeats: 8×3min uphill hard (jog down recovery)
```

**Recovery**: Equal time (1:1 work:rest) or slightly more

### Fartlek

**Purpose**: Unstructured speed, mental training
**Duration**: 30-60min
**Structure**: Mix of paces throughout run

**Example**:
```
15min easy warmup
Then mix:
- 3min hard
- 2min easy
- 5min tempo
- 3min easy
- 1min very hard
- 4min easy
(repeat variations)
15min cool down
```

## Running Volume Progression

### Weekly Mileage Guidelines

**Beginner**: 20-40km/week
**Intermediate**: 40-70km/week
**Advanced**: 70-100km/week
**Elite**: 100-160km/week

### Weekly Increase Rules

**Maximum**: +10% per week OR add 1 session
**Example**:
```
Week 1: 50km (5 runs)
Week 2: 55km (5 runs) ✅
Week 3: 60km (5 runs) ✅
Week 4: 36km (recovery) ✅
Week 5: 63km (5 runs)
```

**Never**: Increase volume AND frequency simultaneously

### Run Frequency

**Beginner**: 3-4 runs/week
**Intermediate**: 4-6 runs/week
**Advanced**: 6-7 runs/week

**Distribution**:
```
5 runs/week:
- 1 long run (30-40% weekly volume)
- 1-2 quality (intervals/tempo)
- 2-3 easy

6 runs/week:
- 1 long
- 2 quality
- 3 easy

7 runs/week:
- 1 long
- 2 quality
- 4 easy (including 1 very short recovery run)
```

## Injury Prevention

### High-Risk Factors

- Rapid volume increase (>10%/week)
- Too much intensity (>20% hard)
- Insufficient recovery
- Weak hips/glutes
- Poor running form
- Old/worn shoes (>500-800km)

### Prevention Strategies

**1. Strength Training (2x/week)**
```
Focus: Hips, glutes, core, ankles

Key Exercises:
- Single-leg squats
- Bulgarian split squats
- Calf raises (straight + bent knee)
- Side planks
- Clamshells
- Hip thrusts
```

**2. Dynamic Warm-Up (Pre-Run)**
```
5-10min routine:
- Leg swings (forward/side)
- Walking lunges
- High knees
- Butt kicks
- A-skips
- B-skips
- Strides (4×100m @ 85% effort)
```

**3. Cooldown + Stretching (Post-Run)**
```
- 10min easy jog/walk
- Static stretching (hold 30-60sec):
  * Calves
  * Hamstrings
  * Quads
  * Hip flexors
  * IT band
```

**4. Foam Rolling**
```
Daily, 10-15min:
- IT band
- Quads
- Calves
- Glutes
- TFL (tensor fasciae latae)
```

### Common Injuries & Management

**Runner's Knee (PFPS)**
- Cause: Weak quads, tight IT band
- Fix: Strengthen quads (eccentric squats), foam roll, reduce mileage

**IT Band Syndrome**
- Cause: Weak hip abductors, high mileage
- Fix: Strengthen glutes, foam roll, avoid cambered roads

**Achilles Tendinitis**
- Cause: Too much volume, hill work
- Fix: Calf strengthening (eccentric), reduce speed work

**Shin Splints**
- Cause: Too much volume too fast, hard surfaces
- Fix: Reduce volume, strengthen tibialis anterior, softer surfaces

**Plantar Fasciitis**
- Cause: Tight calves, weak feet
- Fix: Calf stretching, foot strengthening, night splint

**Red Flags** (See Doctor):
- Sharp pain during run (not just soreness)
- Pain that changes gait
- Swelling
- Pain lasting >2 weeks despite rest

## Running Form

### Optimal Biomechanics

**Cadence**: 170-180 steps/min (both feet)
- Lower cadence = longer ground contact, higher impact
- Higher cadence = reduced impact forces

**Foot Strike**: Midfoot ideal (but individual)
- Avoid overstriding (heel strike far ahead of body)
- Land under center of mass

**Posture**:
- Upright torso (slight forward lean from ankles)
- Relaxed shoulders
- Elbows ~90°
- Eyes forward (10-20m ahead)

**Arm Swing**:
- Forward/back (not across body)
- Relaxed hands (imagine holding potato chips)

### Form Drills (2x/week)

```
After easy run, 10min:

1. High Knees (2×30sec)
2. Butt Kicks (2×30sec)
3. A-Skips (2×30m)
4. B-Skips (2×30m)
5. Bounding (2×30m)
6. Strides (4-6×100m @ 85-90%)
```

## Race-Specific Training

### 5K Training

**Key Sessions**:
- VO2max intervals (5-8min reps)
- Threshold tempo (20-30min)
- Easy volume (60-70km/week advanced)

**Example Week**:
```
Mon: Rest
Tue: 6×1000m @ 5K pace (2:30 recovery)
Wed: 8km easy
Thu: 10km easy + strides
Fri: Rest
Sat: 10km tempo @ threshold
Sun: 16km long run easy
```

### 10K Training

**Key Sessions**:
- Threshold tempo (30-40min)
- VO2max intervals (longer reps)
- Long run (90-120min)

**Example Week**:
```
Mon: Rest
Tue: 5×1600m @ 10K pace (3min recovery)
Wed: 10km easy
Thu: 12km easy + strides
Fri: Rest or 5km recovery
Sat: 12km tempo @ threshold
Sun: 20km long run easy
```

### Half Marathon Training

**Key Sessions**:
- Long runs with race pace segments
- Threshold runs (40-60min)
- Easy volume (70-90km/week advanced)

**Example Week**:
```
Mon: Rest
Tue: 3×15min @ threshold (3min jog)
Wed: 12km easy
Thu: 10km easy + strides
Fri: 8km easy
Sat: 24km long run (last 8km @ race pace)
Sun: 12km easy recovery
```

### Marathon Training

**Key Sessions**:
- Long runs (2.5-3.5h)
- Marathon pace runs
- Threshold work (for speed)

**Peak Week Example**:
```
Mon: Rest
Tue: 16km with 3×10min @ threshold
Wed: 12km easy
Thu: 10km easy
Fri: Rest
Sat: 32km long run (middle 20km @ marathon pace)
Sun: 14km easy recovery
```

**Weekly Volume**: 80-120km (advanced), 60-80km (intermediate)

## Nutrition for Running

### Daily Needs

**Carbs**: 5-7 g/kg body weight (moderate training)
           7-10 g/kg (high volume)

**Protein**: 1.4-1.8 g/kg

**Fats**: 20-30% of total calories

### Pre-Run

**Timing**: 2-3 hours before
**Content**: 1-2 g/kg carbs, low fiber/fat

**Example**:
```
- Toast + banana + honey
- Oatmeal + berries
- Bagel + peanut butter (small amount)
```

### During Run (>90min)

**Target**: 30-60g carbs/hour

**Options**:
- Gels (20-25g carbs each)
- Sports drinks
- Chews
- Real food (dates, bananas)

**Hydration**: 400-800ml/hour (depending on sweat rate)

### Post-Run

**Timing**: Within 30min

**Target**: 1.2 g/kg carbs + 0.25 g/kg protein

**Example** (70kg athlete):
```
84g carbs + 17g protein:
- Chocolate milk (500ml)
- Banana + protein shake
- Rice + chicken
```

## Mental Strategies

### Pacing

**Even Splits**: Safest strategy (identical pace both halves)

**Negative Splits**: Second half faster (requires discipline)

**Positive Splits**: Common mistake (too fast start → fade)

### Race Day Tips

1. **Nothing New**: Gear, nutrition, all tested in training
2. **Warm-Up**: 15-20min easy + 4-6 strides
3. **Start Conservative**: First 2-3km slightly slower than goal
4. **Break it Down**: Focus on 5km segments, not whole race
5. **Mantras**: "Relax", "Strong", "One step at a time"

### Training Partners

**Pros**:
- Motivation
- Push each other on hard days
- Social aspect

**Cons**:
- Easy runs become too fast (ego)
- Can't hit prescribed paces (too slow/fast)

**Best Practice**:
- Run easy days ALONE
- Hard days with similar-ability partners
- Long runs with slower friends (force you to go easy)

## Key Takeaways for AI Plans

✅ **80% easy volume** (Z1-2, conversational pace)
✅ **Max +10% weekly volume increase**
✅ **Respect run tolerance** (athlete-specific max km/week)
✅ **1 long run per week** (30-40% weekly volume)
✅ **1-2 quality sessions** (threshold or intervals)
✅ **No back-to-back hard runs**
✅ **Include strength training** (2x/week for injury prevention)
✅ **Progressive intensity by phase** (base: mostly Z2, peak: add Z4-5)
✅ **Race-specific workouts** (marathon pace for marathon, etc.)
✅ **Taper properly** (reduce volume 30-50%, maintain sharpeners)
