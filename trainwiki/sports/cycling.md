# Cycling Training

## Power-Based Training Zones

### FTP (Functional Threshold Power)

**Definition**: Maximal power you can sustain for ~60 minutes

**Testing**: 20-min all-out test
```
FTP = 95% of 20-min average power

Example:
20-min test: 263W average
FTP = 263 × 0.95 = 250W
```

### Power Zones (Coggan Model)

```
Zone 1 (Active Recovery): <55% FTP    (<137W if FTP=250W)
Zone 2 (Endurance):        56-75% FTP  (140-187W)
Zone 3 (Tempo):            76-90% FTP  (190-225W)
Zone 4 (Lactate Threshold): 91-105% FTP (228-262W)
Zone 5 (VO2max):           106-120% FTP (265-300W)
Zone 6 (Anaerobic):        121-150% FTP (303-375W)
Zone 7 (Neuromuscular):    >150% FTP    (>375W)
```

### Heart Rate Zones (if no power meter)

```
Zone 1: <68% max HR
Zone 2: 69-83% max HR
Zone 3: 84-94% max HR
Zone 4: 95-105% max HR
Zone 5: >106% max HR
```

## Key Cycling Workouts

### Endurance Rides (Zone 2)

**Purpose**: Aerobic base, fat oxidation, volume
**Duration**: 2-6 hours
**Power**: 56-75% FTP
**Cadence**: 85-95 RPM

**Example**:
```
4-hour endurance ride
- First 30min: Z1-2 warmup
- Main: 3h @ steady Z2 (can talk, eat, drink)
- Last 30min: Z2-Z3 if feeling good
```

**Nutrition**: 60-90g carbs/hour

### Sweet Spot (Upper Z3 / Lower Z4)

**Purpose**: High training stress, minimal fatigue
**Power**: 88-93% FTP (sweet spot range)
**Duration**: 2×20min to 3×30min

**Classic Workouts**:
```
1. 2×20min @ 90% FTP (5min recovery)
2. 3×15min @ 92% FTP (5min recovery)
3. 2×30min @ 88% FTP (10min recovery)
```

**When**: Build phase, 1-2x per week
**Benefit**: Efficiency (high TSS without excessive fatigue)

### Threshold Intervals (Zone 4)

**Purpose**: Increase FTP
**Power**: 95-105% FTP
**Duration**: 8-20min reps

**Classic Workouts**:
```
1. 3×12min @ FTP (6min recovery)
2. 2×20min @ 95% FTP (10min recovery)
3. 4×8min @ 105% FTP (4min recovery)
```

**Frequency**: Peak phase, 1x per week

### VO2max Intervals (Zone 5)

**Purpose**: Increase aerobic capacity
**Power**: 110-120% FTP
**Duration**: 3-5min reps

**Classic Workouts**:
```
1. 5×5min @ 115% FTP (5min recovery)
2. 6×4min @ 120% FTP (4min recovery)
3. 10×3min @ 118% FTP (3min recovery)
```

**Frequency**: Peak phase only, 1x per week

### Over-Unders (Threshold Variations)

**Purpose**: Improve lactate clearance
**Structure**: Alternate above/below FTP

**Example**:
```
4×8min intervals:
- 2min @ 105% FTP (over)
- 2min @ 95% FTP (under)
- Repeat 2x within each interval

Recovery: 4min between sets
```

### Hill Repeats

**Purpose**: Power, strength endurance
**Duration**: 4-8min climbs
**Power**: Z4-Z5
**Cadence**: 60-75 RPM (low cadence = strength)

**Example**:
```
6×6min hill @ 105% FTP
- Cadence: 65 RPM
- Recovery: Coast/spin down (5-8min)
```

## Cycling Volume & Frequency

### Weekly Hours

**Beginner**: 4-6 hours/week
**Intermediate**: 8-12 hours/week
**Advanced**: 12-18 hours/week
**Elite**: 18-25+ hours/week

### Ride Distribution

**4-5 rides/week**:
```
- 1 long endurance (40-50% weekly volume)
- 1-2 interval sessions (sweet spot, threshold, VO2max)
- 1-2 easy recovery rides
```

**6-7 rides/week**:
```
- 1 long (3-5 hours)
- 2 interval sessions
- 3-4 endurance/recovery rides
```

## Bike Fit & Efficiency

### Proper Fit Importance

**Poor fit causes**:
- Knee pain (saddle height)
- Lower back pain (reach/drop)
- Numbness (saddle position)
- Inefficient power transfer

**Key Measurements**:
- **Saddle Height**: Heel method (leg fully extended), or 109% inseam
- **Fore/Aft**: Knee over pedal spindle (KOPS) when crank horizontal
- **Reach**: Slight bend in elbows, comfortable back angle

### Pedaling Efficiency

**Cadence Guidelines**:
```
Flat terrain: 85-95 RPM
Climbing: 75-85 RPM
Sprints: 100-110+ RPM
```

**Power Distribution**:
- Goal: Even power through entire pedal stroke
- Monitor: Pedal smoothness (Garmin/Wahoo metrics)
- Drills: Single-leg pedaling (2min each leg)

## Indoor vs. Outdoor Training

### Indoor Trainer Benefits

✅ Controlled intervals (no traffic, lights, terrain)
✅ Precise power targets
✅ Time-efficient
✅ Weather-proof
✅ Safety

**Best For**: Intervals, threshold work, VO2max sessions

### Outdoor Benefits

✅ Mental freshness
✅ Handling skills
✅ Group dynamics
✅ Realistic race simulation
✅ Enjoyment

**Best For**: Long endurance rides, brick workouts, group rides

### Weekly Balance

```
Winter/Off-Season: 60-80% indoor
Build Phase: 50-60% indoor (more intervals)
Peak/Taper: 70-80% outdoor (race-specific)
```

## Race-Specific Training

### Time Trial / Triathlon

**Focus**: Sustained power at FTP, aero position

**Key Sessions**:
```
- 2×20min @ FTP in aero
- 3×15min @ 92% FTP in aero
- Long rides (3-5h) with tempo segments
```

**Position**: Train in race position (aero bars)

### Road Racing / Criterium

**Focus**: Repeated accelerations, high power bursts

**Key Sessions**:
```
- Vo2max intervals: 6×4min @ 120% FTP
- Sprint intervals: 10×30sec all-out (4:30 rest)
- Race simulations (group ride with attacks)
```

### Gravel / Endurance Events

**Focus**: Volume, durability, varied terrain

**Key Sessions**:
```
- Long rides (4-6 hours) at Z2
- Tempo intervals on varied terrain
- Back-to-back long days (Sat/Sun)
```

## Nutrition for Cycling

### On-Bike Fueling

**Target**: 60-90g carbs/hour (rides >90min)

**Options**:
- Gels (25g each)
- Bars (30-40g)
- Drink mix (30-60g/hour)
- Real food (banana, rice cakes)

**Hydration**: 500-800ml/hour (adjust for heat)

### Carb Loading (Before Long Rides/Races)

**72 hours before**:
- 8-10 g/kg body weight carbs/day

**Example** (70kg rider):
- 560-700g carbs/day
- Pasta, rice, bread, oatmeal, fruit

## Bike Maintenance for Training

### Weekly

- Clean chain
- Check tire pressure
- Inspect for damage

### Monthly

- Lube chain properly
- Check brake pads
- Inspect tires for wear

### Quarterly

- Professional tune-up
- Check cassette/chain wear
- Wheel truing if needed

**Safety**: Always ride with spare tube, CO2, multitool

## Key Takeaways for AI Plans

✅ **FTP-based zones** (use % of FTP for workouts)
✅ **80% Z1-2 volume** (majority easy/endurance)
✅ **Sweet spot efficient** (high TSS, low fatigue)
✅ **1 long ride/week** (3-5 hours at Z2)
✅ **Interval progression** (sweet spot → threshold → VO2max)
✅ **Indoor for intervals** (controlled, precise)
✅ **Outdoor for long rides** (mental freshness)
✅ **Cadence targets** (85-95 RPM general)
✅ **Brick workouts** (bike → run for triathlon)
✅ **No back-to-back hard rides** (48h recovery)
