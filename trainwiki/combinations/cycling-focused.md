# Cycling-Focused Training (Road Racing, Gran Fondo, Time Trial)

## Road Racing / Criterium

### Race Demands

**Characteristics**:
- High-intensity efforts (surges, attacks, sprints)
- Repeated accelerations out of corners
- Pack dynamics (drafting, positioning)
- Technical skills (cornering, descending)

### Training Focus

**Primary**: VO2max, anaerobic capacity, repeatability
**Secondary**: Threshold power, endurance

### Weekly Structure (Peak Phase)

```
Monday:    Rest or easy 60min spin
Tuesday:   VO2max intervals: 6×5min @ 115% FTP (5min recovery)
Wednesday: Endurance: 2-3h Z2
Thursday:  Sprint intervals: 8×30sec all-out (4:30 recovery)
Friday:    Easy 60min Z1-2 or Rest
Saturday:  Group ride (race simulation) OR Race
Sunday:    Long endurance: 3-4h Z2
```

### Key Workouts

**1. VO2max Intervals**
```
5×5min @ 115% FTP (5min recovery)
8×3min @ 120% FTP (3min recovery)
10×2min @ 125% FTP (2min recovery)
```

**2. Anaerobic Repeats**
```
10×1min @ 150% FTP (2min recovery)
15×30sec all-out (4min recovery)
```

**3. Race Simulation**
```
2h ride with:
- 10×1min surges @ 130-150% FTP (simulating attacks)
- 5min recovery between
- Stay in pack tempo (Z3) between efforts
```

**4. Cornering Practice**
```
Find criterium course or parking lot
Practice: Brake late, corner fast, accelerate out
Repeat 20-30 laps
```

## Gran Fondo / Sportive

### Race Demands

**Characteristics**:
- Long duration (4-8 hours)
- Sustained climbing
- Pacing discipline
- Nutrition critical

### Training Focus

**Primary**: Endurance, climbing, sustained power
**Secondary**: Threshold, tempo

### Weekly Structure (Peak Phase)

```
Monday:    Rest
Tuesday:   Sweet spot: 3×20min @ 90% FTP
Wednesday: Endurance: 2h Z2
Thursday:  Climbing repeats: 5×8min @ 105% FTP (low cadence)
Friday:    Easy 90min Z2
Saturday:  Long ride: 4-6h (progressive, last 90min @ tempo/threshold)
Sunday:    Endurance: 2-3h Z2 OR Rest
```

### Key Workouts

**1. Long Climb Repeats**
```
Find 8-15min climb
Repeat 3-5× @ 90-95% FTP
Recovery: Descend easy
```

**2. Progressive Long Ride**
```
5-hour ride:
- Hour 1-2: Z2 (60-70% FTP)
- Hour 3-4: Tempo (75-85% FTP)
- Hour 5: Sweet spot (88-93% FTP)
```

**3. Back-to-Back Long Days**
```
Saturday: 5h with climbing
Sunday: 3h Z2 (tired legs)
Goal: Simulate multi-day event fatigue
```

**4. Nutrition Practice**
```
Every long ride:
- 60-90g carbs/hour
- Test race-day foods
- Practice eating while climbing
```

## Time Trial / Triathlon Bike

### Race Demands

**Characteristics**:
- Sustained threshold power (40-60min)
- Aero position comfort
- Pacing precision
- Mental toughness (solo effort)

### Training Focus

**Primary**: FTP, sustained power, position-specific
**Secondary**: Sweet spot, tempo

### Weekly Structure (Peak Phase)

```
Monday:    Rest
Tuesday:   Threshold: 2×20min @ 95-100% FTP (in aero)
Wednesday: Endurance: 2h Z2
Thursday:  Sweet spot: 3×15min @ 92% FTP (in aero)
Friday:    Easy 60min Z2 or Rest
Saturday:  Time trial simulation: 40-60min all-out (in aero)
Sunday:    Long endurance: 3h Z2
```

### Key Workouts

**1. FTP Intervals (in Aero Position)**
```
2×20min @ FTP
2×30min @ 95% FTP
3×15min @ 105% FTP
```

**2. Time Trial Simulation**
```
Warm-up: 20min progressive
Main: 40km all-out (or 60min)
- Hold target watts (95-100% FTP)
- Full aero position
- Practice pacing, nutrition
Cool-down: 15min easy
```

**3. Over-Unders (Threshold Variability)**
```
4×10min:
- 2min @ 105% FTP
- 2min @ 95% FTP
- Repeat

Goal: Improve lactate clearance, threshold power
```

**4. Position Work**
```
All threshold/sweet spot work in aero bars
Build comfort: Start with 50% in aero, progress to 100%
```

## Track Cycling / Velodrome

### Disciplines

**Sprint**: Pure power, 200m
**Pursuit**: 4km sustained @ VO2max
**Points Race**: Repeated accelerations + endurance
**Omnium**: Mix of all

### Training Focus (Pursuit Example)

**Primary**: VO2max, sustained high power
**Secondary**: Anaerobic capacity

**Weekly Structure**:
```
Monday:    Rest
Tuesday:   VO2max: 5×5min @ 115% FTP (on track if available)
Wednesday: Endurance: 2h Z2 (road)
Thursday:  Pursuit simulation: 3×4-5min all-out (10min recovery)
Friday:    Easy spin
Saturday:  Track session: Starts, sprints, tactics
Sunday:    Endurance: 2-3h Z2
```

## Gravel Racing / Ultra-Endurance

### Race Demands

**Characteristics**:
- Very long duration (6-24+ hours)
- Varied terrain (gravel, dirt, pavement)
- Self-supported nutrition
- Durability over power

### Training Focus

**Primary**: Endurance, durability
**Secondary**: Tempo, mental toughness

### Weekly Structure (Peak Phase)

```
Monday:    Rest
Tuesday:   Tempo: 2h with 3×20min @ 80-85% FTP
Wednesday: Endurance: 2-3h Z2 (gravel if possible)
Thursday:  Sweet spot: 2×30min @ 90% FTP
Friday:    Easy 90min or Rest
Saturday:  Long ride: 6-8h (mixed terrain, race pace segments)
Sunday:    Endurance: 3-4h Z2
```

### Key Workouts

**1. Ultra-Long Rides**
```
Week 1: 6 hours
Week 2: 7 hours
Week 3: 8 hours
Week 4: 4 hours (recovery)
Week 5: 9 hours
```

**2. Back-to-Back Long**
```
Saturday: 7-8 hours
Sunday: 4-5 hours
Goal: Simulate multi-day fatigue
```

**3. Self-Supported Practice**
```
Long rides with:
- Carry all food (no stops)
- Practice minimal rest
- Test hydration strategy
- Simulate race conditions
```

## Bike Fit & Aerodynamics

### Importance of Fit

**Poor fit = wasted power, injury, discomfort**

**Key Measurements**:
- Saddle height: 109% inseam (or heel method)
- Saddle fore/aft: KOPS (knee over pedal spindle)
- Reach: Comfortable, slight elbow bend
- Drop: Depends on flexibility, race type

### Aerodynamics (Time Trial / Triathlon)

**Drag Reduction Priority**:
1. **Position** (most important, FREE)
2. **Helmet** (aero vs standard: 30-60 watts saved)
3. **Wheels** (deep section: 10-30 watts)
4. **Frame** (marginal gains)
5. **Clothing** (skinsuit: 5-10 watts)

**Position Optimization**:
- Lower is better (if power maintained)
- Narrow is better (elbows in)
- Test in wind tunnel or with power meter (CdA testing)

## Cycling Nutrition

### Daily Needs

**High-Volume Training** (15+ hours/week):
- **Carbs**: 8-10 g/kg
- **Protein**: 1.6-2.0 g/kg
- **Fats**: 20-25% calories

**Example** (70kg cyclist):
```
Carbs: 560-700g/day
Protein: 112-140g/day
Fats: 70-90g/day
```

### On-Bike Fueling

**Target**: 60-90g carbs/hour (rides >90min)

**Options**:
- Drink mix: 30-60g/hour
- Gels: 2-3/hour (25g each)
- Bars: 1/hour (30-40g)
- Real food: Rice cakes, PB&J, bananas

**Hydration**: 500-800ml/hour
- Electrolytes: 500-1000mg sodium/hour

### Race Day

**Pre-Race** (3-4 hours before):
```
Carbs: 2-3 g/kg
Example (70kg): 140-210g
- Pasta, rice, bread, oatmeal
```

**During Race**:
```
Short (<2h): 30-60g carbs/hour
Long (2-5h): 60-90g carbs/hour
Ultra (5h+): 60-90g + real food
```

## Indoor Training (Zwift, TrainerRoad, Wahoo SYSTM)

### Benefits

✅ **Structured intervals** (precise power targets)
✅ **Time-efficient** (no traffic, stops)
✅ **Weather-proof**
✅ **High TSS in short time**

### Limitations

❌ **Mental fatigue** (boring)
❌ **No handling skills**
❌ **No outdoor experience**
❌ **Overheating** (use fan!)

### Indoor/Outdoor Balance

**Winter**: 70-80% indoor (intervals, base)
**Summer**: 30-40% indoor (only hard intervals)

### Best Indoor Workouts

**1. FTP Builder** (TrainerRoad):
```
2×20min @ 95% FTP
Sweet spot: 3×20min @ 90% FTP
Over-unders: 4×10min (alternating)
```

**2. VO2max Workouts**:
```
Zwift: "The Wringer" (10×3min @ 120% FTP)
TrainerRoad: "Spencer" (12×3min @ 120%)
```

**3. Long Z2** (Zwift):
```
Group ride: 2-3 hours
Benefit: Social, less boring than solo
```

## Key Takeaways for AI Plans

✅ **FTP-based training** (all workouts % of FTP)
✅ **Polarized 80/20** (80% Z1-2, 20% Z4-5)
✅ **Sweet spot efficient** (high TSS, low fatigue)
✅ **Race-specific workouts** (TT = threshold, crit = VO2max)
✅ **Long rides weekly** (3-6 hours depending on event)
✅ **Indoor for intervals** (precise, controlled)
✅ **Outdoor for long/skills** (handling, group dynamics)
✅ **Bike fit critical** (power + comfort + injury prevention)
✅ **Nutrition practice** (all rides >2 hours)
✅ **Taper 2 weeks** (road race), **1 week** (crit)
