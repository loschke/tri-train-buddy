# Duathlon Training (Run-Bike-Run)

## Race Format

**Standard Duathlon**: 10km run → 40km bike → 5km run
**Sprint Duathlon**: 5km run → 20km bike → 2.5km run
**Long Duathlon**: 10-15km run → 60-80km bike → 10km run

## Key Differences from Triathlon

✅ **No swim** (time-efficient training)
✅ **Double run stress** (higher injury risk)
✅ **T1 = Run → Bike** (different from triathlon)
✅ **Final run on fatigued legs** (unique challenge)

---

## Training Focus

### Run Emphasis

**Run Volume**: 60-70% of total (vs 30% in triathlon)
**Bike Volume**: 30-40% of total

**Example** (10 hours/week):
```
Run: 6-7 hours (2 before bike, 4 as standalone)
Bike: 3-4 hours
Strength: 1 hour
```

### Brick Workouts (Critical!)

**Frequency**: 2×/week (more than triathlon)

**Types**:
1. **Run → Bike → Run** (full race simulation)
2. **Bike → Run** (focus on 2nd run)

---

## Weekly Training Structure

### Base Phase (12 weeks)

```
Monday:    Rest
Tuesday:   Run 60min tempo + Strength
Wednesday: Bike 90min Z2
Thursday:  Run 45min easy
Friday:    Bike 60min Z2 + Run 20min easy (brick)
Saturday:  Run 90min long easy
Sunday:    Bike 2h Z2
```

### Build Phase (8 weeks)

```
Monday:    Rest
Tuesday:   Run intervals (8×1000m) + Strength
Wednesday: Bike sweet spot (3×15min)
Thursday:  Run 45min easy
Friday:    Brick: Bike 60min Z3 → Run 20min tempo
Saturday:  Brick: Run 45min Z2 → Bike 2h Z2 → Run 30min
Sunday:    Run 2h long easy
```

### Peak Phase (4-6 weeks)

```
Monday:    Rest or easy 30min run
Tuesday:   Run 10km tempo
Wednesday: Bike intervals (5×5min Z4)
Thursday:  Run 45min easy + strides
Friday:    Short brick: Bike 45min → Run 15min @ race pace
Saturday:  Long brick: Run 30min → Bike 2h → Run 30-45min
Sunday:    Run 90min long easy
```

## Race-Specific Workouts

### Run 1 (First Run) Training

**Goal**: Run hard from standstill (no warm-up)

**Workout**:
```
800m time trial (simulate start)
Rest 10min (walk around)
Repeat 4-6×

Goal: Practice race-start intensity without warm-up
```

### T1 Training (Run → Bike)

**Workout**:
```
1. Run 2km hard (race pace)
2. Quick shoe change to cycling shoes
3. Mount bike, 5min all-out
4. Rest 10min
5. Repeat 3-4×
```

### Run 2 (Off Bike) Training

**Critical Workout** (weekly in peak):
```
Brick: Bike 90min (last 30min @ race pace)
      → Run 30min @ goal Run 2 pace

Goal: Train running on bike-fatigued legs
```

## Injury Prevention

### Higher Run Volume = Higher Risk

**Risk Factors**:
- Double run stress (Run 1 + Run 2 in race)
- Brick workouts (running on fatigue)
- Transitions (explosive starts)

**Prevention**:
1. **Strength 2×/week** (mandatory, not optional)
   - Focus: Hips, glutes, calves
2. **Recovery weeks** (every 3 weeks, not 4)
3. **Gradual volume** (5-8% increase, not 10%)
4. **Easy runs easy** (more temptation to push)

## Race Pacing Strategy

### Run 1

**Effort**: 85-90% (hard but controlled)

**Strategy**:
- First 1km: Find rhythm (not all-out start)
- Middle: Settle into race pace
- Last km: Push to bike transition

### Bike

**Effort**:
- Sprint: 90-95% FTP
- Standard: 85-90% FTP
- Long: 80-85% FTP

**Strategy**:
- First 5km: Settle in, find rhythm
- Middle: Consistent power
- Last 5km: Prepare legs for run (slightly reduce power, increase cadence)

### Run 2

**Effort**: 90-95% (push harder than Run 1)

**Strategy**:
- First 500m: "Jelly legs" are normal, push through
- Find rhythm by 1km mark
- Negative split if possible
- Last km: All-out

**Mental**: "Short run, I can suffer for 20 minutes"

## Transitions

### T1 (Run → Bike)

**Setup**:
- Cycling shoes on bike (already clipped to pedals)
- Helmet open, on handlebars
- Number belt with race number

**Execution**:
1. Run into transition
2. Remove run shoes (elastic laces)
3. Put on helmet
4. Grab bike, run to mount line
5. Mount while putting feet in cycling shoes

**Time Goal**: <45 seconds

### T2 (Bike → Run)

**Setup**:
- Run shoes with elastic laces
- Hat/visor (if using)

**Execution**:
1. Dismount running (unclip early)
2. Rack bike
3. Remove helmet
4. Run shoes on (no tying needed)
5. Grab number belt (if needed), go!

**Time Goal**: <30 seconds

## Nutrition Strategy

### Pre-Race (2-3 hours before)

```
Carbs: 1-2 g/kg
Example (70kg): 70-140g carbs
- Toast + banana + honey
- Oatmeal + berries
```

### Run 1 (10km)

**Nutrition**: None (too short)
**Hydration**: Small sip if very hot

### Bike

**Target**: 60-90g carbs/hour (if >40km)

**Options**:
- Drink mix on bike: 30-40g/hour
- 1-2 gels: 25g each

**Hydration**: 500-750ml/hour

### Run 2 (5-10km)

**Target**: 0-30g carbs (depending on run length)

**Options**:
- 1 gel (if >7km run)
- Aid station sports drink

## Key Takeaways for AI Plans

✅ **Run-heavy volume** (60-70% of total time)
✅ **Brick workouts 2×/week** (peak phase)
✅ **Run → Bike → Run** (full simulation monthly)
✅ **Bike → Run weekly** (train 2nd run fatigue)
✅ **Strength mandatory** (2×/week, injury prevention)
✅ **Recovery every 3 weeks** (not 4, due to double run stress)
✅ **Practice transitions** (T1 different from triathlon)
✅ **Final run race pace** (brick workout must include this)
✅ **Conservative run volume increases** (max 8%/week)
✅ **No swim time** (can train more run/bike)

## Sample Peak Week

```
Monday:    Rest + Foam rolling

Tuesday:   AM: Run 45min with 3×10min tempo
           PM: Strength (lower body + core)

Wednesday: Bike 90min sweet spot (3×20min @ 90% FTP)

Thursday:  Run 45min easy + 6×100m strides

Friday:    Short brick:
           - Bike 45min progressive (finish @ race pace)
           - Run 15-20min @ goal Run 2 pace

Saturday:  Long brick:
           - Run 30-40min @ Z2-3
           - Bike 2 hours (last 45min @ race pace)
           - Run 30min (progressive, finish strong)

Sunday:    Run 90min long easy

Total: ~11 hours (Run: 7h, Bike: 4h)
```
