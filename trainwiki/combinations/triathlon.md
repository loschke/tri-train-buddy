# Triathlon-Specific Training

## Unique Challenges of Triathlon

### Multi-Sport Balance

**Challenge**: Train 3 sports + transitions without overtraining

**Solution**: Prioritize weakest discipline (limiters)

**Weekly Distribution Example**:
```
Total: 12 hours

Swim: 2h (17%) - Strongest
Bike: 6h (50%) - Biggest gains, lowest injury risk
Run:  4h (33%) - High impact, conservative volume
```

### Energy Management

**Challenge**: Swim → Bike → Run (cumulative fatigue)

**Key**: Train "off the bike" running

## Brick Workouts

### Definition

**Brick**: Two disciplines back-to-back (typically bike → run)

**Purpose**:
- Simulate race-day fatigue
- Train running on tired legs
- Practice transitions

### Types of Bricks

**1. Short Brick (Weekly Maintenance)**
```
Bike: 60-90min Z2
Run: 15-30min Z2 immediately after

Goal: Get used to "jelly legs" sensation
Frequency: 1×/week (build/peak)
```

**2. Long Brick (Race Simulation)**
```
Bike: 2-4 hours (include race pace segments)
Run: 45-90min (include race pace)

Example:
- Bike 3h: 2h Z2, 1h @ race pace
- Run 60min: First 30min Z2, last 30min @ race pace

Frequency: Every 2-3 weeks (peak phase)
```

**3. Intensity Brick**
```
Bike: 90min with intervals (e.g., 3×15min Z4)
Run: 30min tempo

Goal: Train high intensity + transition fatigue
Frequency: 1×/2 weeks (peak phase)
```

### Brick Workout Progression

**Base Phase**: No bricks (build individual sports)

**Build Phase**: 1× short brick every 1-2 weeks
```
Week 1: Bike 90min Z2 → Run 20min Z2
Week 3: Bike 90min Z2 → Run 30min Z2
```

**Peak Phase**: 1× brick per week
```
Week 1: Short brick (bike 60min → run 20min)
Week 2: Long brick (bike 3h → run 60min)
Week 3: Intensity brick (bike intervals → run tempo)
Week 4: Recovery (no brick)
```

## Transition Training

### T1 (Swim → Bike)

**Practice**:
```
1. Wetsuit removal (pool deck practice)
2. Run to bike in cycling shoes (clip shoes to pedals, mount with them)
3. Swim 400m hard → 5min bike (simulate first km)
```

**Time Savers**:
- Wetsuit: Body glide, practice pulling off
- Bike shoes: Already clipped to pedals, fly-mount

### T2 (Bike → Run)

**Practice**:
```
1. Dismount running (slow down, unclip early)
2. Quick shoe change (elastic laces)
3. Run first 100m to find rhythm
```

**Time Savers**:
- Elastic laces (no tying)
- Bike shoes stay on bike
- Race belt with number (no pinning)

### Transition Workouts

**Standalone Session (Peak Phase, 1×/month)**:
```
1. Swim 400m hard
2. Quick wetsuit removal
3. Run to "bike" (stationary in transition area)
4. Mount bike shoes
5. Bike 5min hard
6. Dismount
7. Run 1km

Rest 10min, repeat 2-3×
```

## Race-Specific Training

### Sprint Triathlon (750m / 20km / 5km)

**Focus**: High intensity, pacing, transitions

**Weekly Structure** (Peak Phase):
```
Monday:    Rest
Tuesday:   Swim: 10×100m @ race pace
           Run: 6×800m intervals
Wednesday: Bike: 60min with 3×10min Z4
Thursday:  Swim: Technique + 500m TT
Friday:    Run: Easy 30min + strides
Saturday:  Brick: Bike 45min Z3-4 → Run 15min @ race pace
Sunday:    Run: 10km easy OR Bike: 90min Z2
```

**Key Sessions**:
- Swim at/above race pace (short reps)
- Bike threshold work
- Run speed (800m-1km reps)
- Weekly brick

### Olympic Triathlon (1.5km / 40km / 10km)

**Focus**: Sustained pace, pacing discipline

**Weekly Structure** (Peak Phase):
```
Monday:    Swim: Technique + endurance
Tuesday:   Bike: Sweet spot intervals (3×15min)
           Run: Tempo 30min
Wednesday: Swim: 5×200m @ threshold
Thursday:  Bike: 90min Z2
Friday:    Run: Easy 45min
Saturday:  Brick: Bike 2h (1h Z2, 1h race pace) → Run 30min
Sunday:    Run: 90min long easy
```

**Key Sessions**:
- Swim threshold sets
- Bike sweet spot / race pace
- Run tempo
- Bi-weekly long brick

### Half Ironman (1.9km / 90km / 21km)

**Focus**: Endurance, nutrition, pacing

**Weekly Structure** (Peak Phase):
```
Monday:    Swim: 3km aerobic
Tuesday:   Bike: 2h sweet spot work
           Run: 45min easy
Wednesday: Swim: 1h technique/threshold mix
Thursday:  Bike: 90min Z2
Friday:    Run: Tempo 45min OR Rest
Saturday:  Brick: Bike 4h (progressive, last 90min race pace)
                  → Run 60min (first 30min Z2, then race pace)
Sunday:    Run: 2h long easy OR Swim 2km easy
```

**Key Sessions**:
- Long brick (4h bike → 60min run)
- Bike sweet spot volume
- Run marathon pace segments
- Nutrition practice (brick workouts)

### Full Ironman (3.8km / 180km / 42km)

**Focus**: Endurance, durability, energy management

**Peak Weekly Structure** (20+ hours):
```
Monday:    Swim: 3.5km endurance + Core
Tuesday:   Bike: 3h sweet spot
           Run: 60min easy
Wednesday: Swim: 3km threshold work
Thursday:  Bike: 2h Z2 + Run: 30min off bike
Friday:    Swim: 2km easy + Run: 45min easy
Saturday:  Bike: 5-6h (4h Z2, 2h race pace) → Run: 30-45min
Sunday:    Run: 2.5-3h long (progressive, finish strong)
```

**Key Sessions**:
- Long bike (5-6 hours with race pace)
- Long run (2.5-3 hours)
- Back-to-back long days (Sat/Sun)
- Nutrition dialed in (60-90g carbs/hour)

## Triathlon-Specific Periodization

### Example: Ironman (32 Weeks)

**Weeks 1-12: Base Phase**
```
Volume: Low-moderate (8-14h/week)
Intensity: 85% Z1-2
Focus: Build aerobic base in all 3 sports
Strength: 2×/week (anatomical adaptation)
Bricks: None
```

**Weeks 13-24: Build Phase**
```
Volume: Moderate-high (14-20h/week)
Intensity: 80% Z1-2, 20% Z3-4
Focus: Progressive volume, add threshold work
Strength: 2×/week (max strength)
Bricks: 1× every 2 weeks (short)
```

**Weeks 25-29: Peak Phase**
```
Volume: Peak (18-22h/week)
Intensity: 75% Z1-2, 25% Z4-5
Focus: Race-specific sessions, bricks
Strength: 1×/week (maintenance)
Bricks: 1×/week (long + short)
```

**Weeks 30-32: Taper**
```
Week 30: 70% volume (12-15h)
Week 31: 50% volume (9-11h)
Week 32: 30% volume (6-7h + RACE)

Intensity: Maintain sharpeners, mostly easy
Bricks: 1× short (week 30), none after
```

## Limiter-Based Training

### Identify Limiters

**Swim Limiter** (slowest relative to age group):
- Increase swim volume 20-30%
- Add 4th swim session
- Reduce weakest other sport slightly

**Bike Limiter**:
- Increase long ride duration
- Add sweet spot intervals
- Most "ROI" (lowest injury risk, high volume capacity)

**Run Limiter**:
- Careful volume increase (10% max)
- More brick workouts (train off bike)
- Strengthen hips/glutes (injury prevention)

### Example Adjustments

**Standard Distribution** (12h/week):
```
Swim: 2h, Bike: 6h, Run: 4h
```

**Swim Limiter** (adjust to 13h):
```
Swim: 3h (+1h) ✅
Bike: 6h (maintain)
Run: 4h (maintain)
```

**Run Limiter** (adjust to 13h):
```
Swim: 2h (maintain)
Bike: 5.5h (-0.5h)
Run: 5.5h (+1.5h) ✅
```

## Triathlon Nutrition Strategy

### Daily Fueling

**Carbs**: 6-10 g/kg (depending on volume)
**Protein**: 1.6-2.0 g/kg
**Fats**: 20-30% calories

**Example** (70kg athlete, 16h training/week):
```
Carbs: 490-560g/day
Protein: 112-140g/day
Fats: ~70-90g/day
```

### Race Day Nutrition

**Swim**: Nothing (too short, stomach full not ideal)

**Bike**:
```
Target: 60-90g carbs/hour
- Drink mix: 30-40g/hour
- Gels: 2-3 per hour (25g each)
- Bars: 1 per 90min (30-40g)
- Real food (banana, rice cake) OK

Hydration: 500-800ml/hour
- Electrolytes critical (sodium 500-1000mg/hour)
```

**Run**:
```
Target: 30-60g carbs/hour (stomach more sensitive)
- Gels: 1-2 per hour
- Sports drink at aid stations
- Water + salt tablets

Hydration: 400-600ml/hour
- Smaller sips more frequently
```

### Practice Fueling

**All brick workouts**: Practice race nutrition
**Long bike/run**: Test gels, drinks, timing
**Experiment in training, perfect in race**

## Common Triathlon Mistakes

### ❌ Mistake 1: Too Much Swimming

**Problem**: Swim is <10% race time, gets 30% training time

**Solution**: Limit swim to 15-20% weekly volume (unless major limiter)

### ❌ Mistake 2: Neglecting Brick Workouts

**Problem**: Running off bike is unique stress

**Solution**: 1× brick per week in peak phase

### ❌ Mistake 3: Too Much Intensity

**Problem**: Mixing 3 sports = easy to overtrain

**Solution**: 80/20 rule ACROSS all sports

### ❌ Mistake 4: Ignoring Transitions

**Problem**: Waste 2-5min in transitions

**Solution**: Practice T1/T2 monthly, smooth = fast

### ❌ Mistake 5: No Race Rehearsal

**Problem**: Nutrition, pacing untested

**Solution**: 1-2 full dress rehearsals (6-8 weeks out)

## Race Pacing Strategy

### Swim

**Goal**: Controlled effort, save legs for bike/run

**Effort**: 85-90% (not all-out)
**Sighting**: Every 6-10 strokes
**Drafting**: Save 10-20% energy if possible

### Bike

**Goal**: Strong but sustainable (not leaving it all on bike)

**Effort**:
- Sprint: 90-95% FTP
- Olympic: 85-90% FTP
- Half: 80-85% FTP
- Ironman: 70-75% FTP

**Pacing**: Even power, slightly conservative first 25%

### Run

**Goal**: Negative split if possible

**Pacing**:
- First 25%: 5-10sec/km SLOWER than goal pace
- Middle 50%: At goal pace
- Last 25%: Push if feeling good

**Mantras**: "Run your own race", "Patient early, strong late"

## Key Takeaways for AI Plans

✅ **Sport balance** (50% bike, 30% run, 20% swim typical)
✅ **Brick workouts** (1×/week peak, every 2 weeks build)
✅ **Train limiters** (adjust volume to weakest discipline)
✅ **Run off bike** (brick workouts critical for triathlon)
✅ **80/20 across all 3** (not per sport, but total)
✅ **Long brick every 2-3 weeks** (race simulation)
✅ **Transition practice** (T1/T2 monthly in peak)
✅ **Nutrition rehearsal** (all long workouts)
✅ **Taper all 3 sports** (proportional volume reduction)
✅ **Rest days critical** (3 sports = high fatigue risk)
