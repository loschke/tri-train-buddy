# Running-Focused Training (Marathon, Half Marathon, Ultra)

## Marathon Training

### Training Phases (16-20 Week Plan)

**Weeks 1-8: Base Building**
```
Volume: 50-80km/week (intermediate)
Long Run: 20-25km
Quality: 1× tempo per week
Focus: Aerobic foundation
```

**Weeks 9-14: Build Phase**
```
Volume: 70-100km/week (peak)
Long Run: 28-35km
Quality: 1× tempo, 1× intervals
Focus: Marathon pace practice, threshold
```

**Weeks 15-18: Peak Phase**
```
Volume: Maintain 80-100km
Long Run: 32-36km (2-3 times)
Quality: Marathon pace long runs
Focus: Race-specific workouts
```

**Weeks 19-20: Taper**
```
Week 19: 60-70% volume
Week 20: 40-50% volume + RACE
Long Run: Week 19: 20km, Week 20: None
```

### Key Marathon Workouts

**1. Long Run Progression**
```
Week 1-4:   20-24km @ easy pace
Week 5-8:   24-28km @ easy pace
Week 9-12:  28-32km (last 8-10km @ marathon pace)
Week 13-16: 32-36km (last 12-16km @ marathon pace)
Week 17-18: 30-32km (50% @ marathon pace)
Week 19:    20km easy
Week 20:    RACE
```

**2. Marathon Pace Runs**
```
Start: 3×3km @ goal marathon pace (2min jog)
Progress: 2×8km @ marathon pace (3min jog)
Peak: 16-20km continuous @ marathon pace
```

**3. Threshold Tempo**
```
Base: 20min @ threshold (10K pace)
Build: 30-40min @ threshold
Peak: 2×20min @ threshold (5min jog)
```

**4. Long Intervals** (Build Phase)
```
6×1600m @ 10K pace (400m jog recovery)
5×2000m @ half marathon pace (2min jog)
```

### Marathon Pacing Strategy

**Even Splits**: Most reliable

**Negative Splits**: Second half faster
```
Example (3:30 goal, 4:58/km average):
KM 1-21:  5:03/km (slightly slower)
KM 22-42: 4:53/km (slightly faster)
```

**Positive Splits**: Avoid! (too fast start = crash)

**Wall Prevention**:
- Fuel 30-60g carbs/hour (start at km 8)
- Hydrate at every aid station
- Conservative first half
- Practice nutrition in training

## Half Marathon Training

### Training Plan (12 Weeks)

**Volume Progression**:
```
Weeks 1-4:  40-55km/week
Weeks 5-8:  50-65km/week
Weeks 9-11: 60-75km/week
Weeks 12:   40km (taper)
```

### Key Half Marathon Workouts

**1. Tempo Runs**
```
Week 1-4:  20min @ threshold
Week 5-8:  30-40min @ threshold
Week 9-11: 45-50min @ threshold
```

**2. Long Run**
```
Week 1-4:  16-18km easy
Week 5-8:  18-20km (last 5km @ race pace)
Week 9-11: 20-22km (last 8km @ race pace)
Week 12:   12km easy
```

**3. Intervals**
```
8×800m @ 5K pace (90sec jog)
6×1km @ 10K pace (400m jog)
5×1600m @ half marathon pace (2min jog)
```

### Half Marathon Pacing

**Conservative Start**: First 5km 5-10sec/km slower than goal

**Steady Middle**: KM 6-15 at goal pace

**Strong Finish**: KM 16-21 push if feeling good

## 10K Training

### 8-Week Plan

**Volume**: 40-60km/week

**Weekly Structure**:
```
Monday:    Rest
Tuesday:   Intervals (6×1000m @ 5K pace)
Wednesday: Easy 8-10km
Thursday:  Tempo 30min @ threshold
Friday:    Easy 6km or Rest
Saturday:  Long run 14-16km
Sunday:    Easy 8-10km
```

### Key 10K Workouts

**1. VO2max Intervals**
```
8×800m @ 5K pace (2:30 jog)
6×1000m @ 5K pace (2min jog)
5×1200m @ 5K pace (90sec jog)
```

**2. Threshold Tempo**
```
2×15min @ 10K pace (3min jog)
3×10min @ 10K pace (2min jog)
Continuous 30min @ threshold
```

**3. Long Run**
```
12-16km @ easy pace
(10K training = shorter long runs, more speed)
```

## 5K Training

### 6-Week Plan

**Volume**: 35-50km/week

**Focus**: Speed, VO2max, lactate tolerance

**Weekly Structure**:
```
Monday:    Rest
Tuesday:   VO2max (8×400m @ mile pace)
Wednesday: Easy 6-8km
Thursday:  Tempo 20-25min @ threshold
Friday:    Easy 5km + strides
Saturday:  Intervals (5×1000m @ 5K pace)
Sunday:    Long run 12-14km
```

### Key 5K Workouts

**1. VO2max Intervals** (primary focus)
```
12×400m @ mile pace (60-90sec jog)
8×600m @ 3K pace (90sec jog)
6×800m @ 5K pace (2min jog)
```

**2. Threshold Work**
```
2×12min @ threshold (3min jog)
Continuous 20-25min @ threshold
```

**3. Race Pace Intervals**
```
5×1000m @ 5K race pace (2min jog)
3×1600m @ 5K pace (3min jog)
```

## Ultra Marathon Training (50K - 100K+)

### Unique Challenges

- **Volume**: Very high weekly km
- **Time on Feet**: 3-6+ hour runs
- **Fueling**: Critical (100g+ carbs/hour)
- **Mental**: Extreme endurance
- **Terrain**: Often trail, hills, technical

### Training Principles

**Back-to-Back Long Runs**:
```
Saturday:  3-4 hours
Sunday:    2-3 hours
Goal: Simulate race-day fatigue
```

**Vertical Gain**:
- If race has 2000m climbing → train hills weekly
- Hill repeats + long climbs

**Nutrition Practice**:
- Every long run (>2h): Practice race nutrition
- Real food (not just gels): Sandwiches, nuts, etc.

### Sample Ultra Week (50K/100K)

```
Monday:    Rest or easy 30min
Tuesday:   Run 90min with hills
Wednesday: Run 60min easy
Thursday:  Run 90min tempo (segments)
Friday:    Rest or easy 30-45min
Saturday:  Long run 4-5 hours (race-specific terrain)
Sunday:    Long run 2-3 hours (easy pace)

Total: 80-120km/week
```

**Key**: Time on feet > pace

## Trail Running Training

### Trail-Specific Skills

**Downhill Running**:
- Eccentric quad strength (destroys legs)
- Practice bombing downhills

**Uphill Power Hiking**:
- Often faster than slow running on steep climbs
- Train with poles if race allows

**Technical Terrain**:
- Agility, foot placement
- Practice on rocks, roots, varied terrain

### Trail Running Workouts

**1. Hill Repeats**
```
8×3-5min hard uphill
- Uphill: Hard effort
- Downhill: Controlled descent (practice technique)
```

**2. Long Trail Run**
```
3-5 hours on trail
Focus: Time on feet, not distance
Pace slower than road (terrain-dependent)
```

**3. Fartlek on Trail**
```
60-90min continuous
Mix: Surge uphills, recover downhills/flats
Unstructured, effort-based
```

## Strength Training for Runners

### Essential Exercises (2×/week)

**Lower Body**:
```
- Single-leg squats: 3×10 each
- Bulgarian split squats: 3×8 each
- Calf raises: 3×20 (straight + bent knee)
- Hip thrusts: 3×12
```

**Core**:
```
- Planks: 3×45-60sec
- Side planks: 3×30-45sec each
- Dead bugs: 3×10 each side
```

**Injury Prevention**:
```
- Clamshells: 3×20 each (daily)
- Monster walks: 3×20 steps each direction
- Single-leg balance: 60sec each leg
```

## Running Nutrition

### Daily Needs (Marathon Training)

**Carbs**: 7-10 g/kg body weight
**Protein**: 1.6-2.0 g/kg
**Fats**: 20-25% calories

**Example** (70kg runner, 100km/week):
```
Carbs: 490-700g/day
Protein: 112-140g/day
Fats: ~70-80g/day
```

### Race Fueling

**Marathon**:
```
Target: 30-60g carbs/hour
Start: KM 8-10 (before glycogen depletes)
Options: Gels every 5km, sports drink
```

**Ultra**:
```
Target: 60-90g carbs/hour (higher due to slower pace)
Mix: Gels, bars, real food (savory options for variety)
```

## Key Takeaways for AI Plans

✅ **80% easy volume** (Z1-2, conversational)
✅ **1 long run/week** (30-40% weekly volume)
✅ **1-2 quality sessions** (tempo, intervals)
✅ **Marathon pace runs** (critical for marathon training)
✅ **Progressive long runs** (build from 20km to 35km)
✅ **Taper 2-3 weeks** (marathon/ultra)
✅ **Strength 2×/week** (injury prevention mandatory)
✅ **Recovery weeks every 3-4** (40% volume reduction)
✅ **Nutrition practice** (all runs >90min)
✅ **Race-specific terrain** (trail for trail race, etc.)
